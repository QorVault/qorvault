# Payee allowlist — exact payee strings the operator has decided are
# organizations and may be published by name.
#
# EVERY ENTRY HERE IS AN OPERATOR DECISION. The file shipped empty as a
# scaffold; on 2026-09-18 the operator ruled on the top 150 withheld payees
# and approved the 117 organisations below (round 1). Every personal name
# in that range was held, as were three organisations pending review. No
# agent decides who is a business: an agent writes the operator's list and
# nothing else. test_payees.py pins this file to exactly those 117 keys,
# so an unreviewed addition, removal or respelling fails the suite.
#
# FORMAT
#   One payee string per line, exactly as it is printed on the voucher
#   listing. Blank lines are ignored. A line whose first non-space
#   character is "#" is a comment; no payee in this corpus begins with "#"
#   (measured 2026-09-16 over all 13,306 payees, count = 0).
#
# HOW AN ENTRY IS MATCHED
#   On this package's normal payee key: leading and trailing whitespace
#   trimmed, runs of internal whitespace collapsed to one space, trailing
#   . , - & ; stripped, then case-folded. That is the same key the corpus
#   uses to decide two printed spellings are one payee, so an entry
#   releases exactly one payee identity. It is NOT a substring match and
#   NOT a pattern: "KCDA" does not release "KCDA Warehouse".
#
# WHAT AN ENTRY OVERRIDES
#   Every name pattern — the business-marker list and the "Surname, Given"
#   person guard both. An allowlisted payee is published.
#
# WHAT AN ENTRY DOES NOT OVERRIDE
#   The Payroll Handwrite signal. If any of a payee's own lines carries a
#   "Payroll Handwrite" description, the district's own records say that
#   payee is an employee being handed a cheque, and the name stays
#   withheld even if it is listed here. Nothing is silently ignored: the
#   session report names the payees this applies to.
#
# WHERE TO GET THE CANDIDATES
#   reports/withheld-payees-2026-09-16.csv lists every withheld payee with
#   its line count, first and last cycle, the reason it was withheld, and
#   a flag for bare acronyms and all-caps names. That file is the
#   worksheet for this one. It is NOT committed — it contains individuals'
#   names.
#
